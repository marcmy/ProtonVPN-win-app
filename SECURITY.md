# Security policy

This repository is an unofficial fork of Proton VPN for Windows. It is not a
Proton-operated security support channel.

## Reporting a vulnerability

For a vulnerability introduced by this fork, use
[GitHub private vulnerability reporting](https://github.com/marcmy/ProtonVPN-win-app/security/advisories/new).
Please include the affected commit or build, reproduction steps, impact, and any
suggested mitigation. Do not open a public issue containing exploit details,
credentials, VPN logs with personal data, or other secrets.

For a vulnerability in Proton's official client or service, report it directly
through [Proton's security program](https://proton.me/security/security-policy).

## Supported code

Security fixes target the current `marc/proton` branch and patch artifacts built
from it. Older fork branches and patches are not supported once the maintained
branch moves to a newer upstream release.
